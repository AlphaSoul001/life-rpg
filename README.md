# Life RPG

A standalone, local-first RPG-style life dashboard inspired by the provided reference screenshots.

## Included
- Character dashboard with HP, Mood, Focus, Motivation
- XP and level progression
- Six core stats + radar chart
- Quest creation and completion
- Energy actions and resource trade-offs
- Habit streak tracking
- Boss fights
- Character Arc chapters
- Reward shop with coins
- Daily event logs and performance chart
- Responsive desktop/mobile layout
- Automatic persistence using browser localStorage

## Run
Open `index.html` directly in a browser, or serve this folder with any static web server.

No backend or API key is required for the prototype.
